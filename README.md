# 🚀 ERP Logistics Full Stack System

Sistema integral de gestión logística desarrollado con **Arquitectura Limpia (Clean Architecture)**, conectando un ecosistema Web y Móvil bajo un mismo Backend de alto rendimiento.

## 🛠️ Stack Tecnológico
*   **Backend:** .NET 8, Web API, CQRS con MediatR, Entity Framework Core.
*   **Web Frontend:** React 18, TypeScript, Tailwind CSS / Shadcn UI.
*   **Mobile App:** React Native, Axios para integración de API.
*   **Base de Datos:** SQL Server.

## 🏗️ Arquitectura y Patrones
*   **Clean Architecture:** Separación clara de responsabilidades (Domain, Application, Infrastructure, API).
*   **CQRS:** Segregación de consultas y comandos para escalabilidad.
*   **Repository Pattern:** Abstracción del acceso a datos.
